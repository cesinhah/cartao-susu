# Cartão Susu

Painéis interativos de gastos extraídos das faturas Itaú (Set/2025 → Ago/2026).

- **suelen.html** — apenas os gastos do cartão adicional da Suelen
- **gastos.html** — overview geral (sem o cartão da Suelen)

Os dados estão embutidos nos próprios arquivos HTML (sem dependência de servidor).
